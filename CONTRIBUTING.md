# Contributing

Thank you for your interest in contributing! Here's how you can share your code:

## How to Contribute

1. **Fork** this repository by clicking the "Fork" button at the top right of the repo page.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/abdullaha1-ship-it.github.io.git
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b my-feature
   ```
4. **Make your changes** and commit them:
   ```bash
   git add .
   git commit -m "Describe your changes"
   ```
5. **Push** your branch to your fork:
   ```bash
   git push origin my-feature
   ```
6. **Open a Pull Request** from your fork's branch to this repository's `main` branch.

## Guidelines

- Keep changes focused and minimal.
- Write clear commit messages describing what you changed.
- If you're fixing a bug, describe the problem and how your change fixes it.
- If you're adding a feature, explain what it does and why it's useful.

## Questions?

If you have any questions, feel free to open an [issue](https://github.com/abdullaha1-ship-it/abdullaha1-ship-it.github.io/issues).
